## 3. 발견 — 다음 개정 반영 대상

### 3.1 [중] Ŝ ∈ (1, 1+delta_r) 구멍은 "발산을 수렴으로 뒤집는다"

검토는 이 구간이 `max_iter` 로 떨어지고 거기서 `err` 이 음수가 된다고 봤다.
**실제로는 그 자리에서 `'converged'` 가 찍힌다.**

```
Ŝ = 1.02  →  err_iterate = |resid| / (1 − 1.02) = |resid| / (−0.02)  < 0
판정식:      err_iterate < eps_conv × MTOW_k
             (음수)      <  (양수)                →  항상 참
```

§2.4 어디에도 `Ŝ < 1` 전제가 없어 분모가 음수가 되는 순간 판정식이 무조건 통과한다.
검토가 제안한 `r̂ ≥ 1 → diverged`(deadband 없음) 로 막히지만, **판정식 자체에도
`Ŝ < 1` 을 명시**해 두 겹으로 막았다. 회귀 테스트 5번이 이 자리를 지킨다.

### 3.2 [중] 리밋 사이클은 출하 설정(relax=1.0)에서 발생하지 않는다

§3.2 는 "슬라이서 계단형 출력 → `r̂≈−1` 무한진동"을 `limit_cycle` 신설 근거로 들었다.
**relax=1 에서는 이 현상이 원리적으로 불가능하다.**

relax=1 이면 반복식이 `M_{k+1} = g(M_k)` 이고, `g` 가 단조증가면 2-주기 궤도가 없다
(`a<b`, `f(a)=b>a`, `f(b)=a<b` 이면 `f(a)>f(b)` 로 단조성 모순).
`W_str` 이 MTOW 에 대해 단조증가인 한 계단형이어도 마찬가지다.
relax>1 이면 `M_{k+1} = (1−relax)M_k + relax·g(M_k)` 의 계수가 음수라 비로소 감소
사상이 될 수 있다.

실측 — 양자 크기를 400배(0.005→2.0) 훑어도 relax=1.0 에서는 전부 `converged`:

| quantum | 0.005 | 0.02 | 0.1 | 0.5 | 2.0 |
|---|---|---|---|---|---|
| status (relax=1.0) | converged | converged | converged | converged | converged |

`limit_cycle` 이 나온 것은 **relax ≥ 2.0** 부터다.

**함의:** `limit_cycle` 기계는 §7.4 스윕 격자(relax 0.3~3.0)에는 필요하지만
**출하 설정과 §5-12 상향 범위(1.25~1.35)에서는 발동하지 않는다.**
"특정 형상대가 통째로 탈락한다"는 위험은 출하 설정에는 없다.
다만 `W_str` 이 국소적으로 **비단조**인 회귀식이면 relax=1 에서도 가능하므로
기계 자체는 보험으로 유지할 값어치가 있다. 테스트 8이 이 성질을 고정한다.

### 3.3 [소] `eps_conv ≤ resid_floor/(1−Ŝ)` 이면 하한 가드가 판정을 선점한다

수렴 판정은 `|resid| < eps·(1−Ŝ)·MTOW`, 하한 가드는 `|resid| < resid_floor·MTOW` 에서
걸린다. 따라서 `eps·(1−Ŝ) < resid_floor` 면 가드가 항상 먼저다.

실측 (resid_floor=1e-6, S=0.21 → 예측 임계 `1e-6/0.79 = 1.27e-6`):

| eps_conv | 1e-3 | 1e-5 | **1e-6** | 1e-7 | 1e-8 |
|---|---|---|---|---|---|
| status | converged | converged | converged | converged | converged |
| S_hat | 0.2100 | 0.2100 | **None** | None | None |

예측 임계와 관측이 정확히 일치한다. status 는 `converged` 로 나오지만 `S_hat=None` 이라
**오차 보고가 불가능해진다.** `eps_conv ≤ resid_floor` 를 입력 예외로 막았다.

### 3.4 [소] relax > 2 영역에 `diverged` 오탐이 있다

`quantum=0.05, relax=2.3` 에서 초반 6회의 일시적 `|resid|` 증가가 `r̂ ≤ −1.05` 3연속을
만들어 `diverged` 로 조기 탈락시킨다. 탐지를 끄고 45회 돌리면 `|resid|` 가
`0.120 → 0.00295` 로 **줄어든다** (0.02배). 즉 발산이 아니었다.

대조군 `quantum=0.37, relax=2.2` 는 `|resid|` 가 3.6배 증가하고 `MTOW_k` 범위가
[5.86, 7.77] 로 확산되므로 `diverged/numerical` 이 **정답**이다
(진짜 고정점이 존재하지만 relax 선택 때문에 멀어지는 경우 — §3.3 이 나눈 그 구분).

출하 설정에는 없는 문제지만 §7.4 스윕 지도에 영향이 있다. 완화안은
"연속 N회" 대신 "최근 N회의 `|resid|` 추세가 단조 증가" 같은 조건이나, 판단은
게이트 2 실측 후로 미룬다.

### 3.5 [참고] `limit_cycle` 의 `err = 0` 은 버그가 아니다

`quantum=0.02, relax=2.0` 에서 `err=0` 이 나온다. 이력을 보면 반복값 `MTOW_k` 만
두 값 사이를 진동하고 **반환 대상 `MTOW_raw` 는 6.864444444 로 완전히 고정**이다.
`g(raw)=raw` 가 정확히 성립하므로 그 값이 참 고정점이고 오차 0 이 맞다.
두 분기가 서로 다른 양자 구간에 들어가는 경우(`relax=2.5`)에는 `err=0.03` 으로
두 반환값 차(0.06)의 절반이 정확히 나온다.

## 4. resid_floor·양자화 실측 (§2.6, §5-14)

`sizing/measure_noise.py` — MTOW 를 좁게 훑어 `W_str` 응답의 산포와 이산 격자를 잰다.
`resid = W_fixed + W_str(MTOW) − MTOW` 에서 `W_fixed`·`MTOW` 는 정확하므로
resid 의 불확실성은 곧 `W_str` 의 불확실성이다.

스텁 시연 결과 (중심 MTOW=6.87, 401점):

| 모델 | 국소 S | 산포 | 양자 | 권고 floor_rel |
|---|---|---|---|---|
| 선형 S=0.21 | 0.2100 | 1.10e-16 | 연속 | 4.82e-17 |
| 멱함수 a=.35 b=.92 | 0.2760 | 2.27e-08 | 연속 | 9.92e-09 |
| 양자화 q=0.02 | 0.1639 | 5.75e-03 | **2.000e-02** | 1.46e-03 |
| 양자화 q=0.002 | 0.2085 | 5.20e-04 | **2.000e-03** | 1.46e-04 |
| 선형+노이즈 1e-9 | 0.2100 | 1.02e-09 | 연속 | 4.43e-10 |
| 선형+노이즈 1e-6 | 0.2100 | 1.02e-06 | 연속 | 4.43e-07 |

양자화 두 경우 모두 **양자 크기를 정확히 복원**한다.

> **측정상 함정 하나:** 창이 양자보다 좁으면 표본이 전부 한 계단 안에 들어가
> 고유값 1개, 양자 0 이라는 무의미한 답이 나온다. 그 권고값(0)을 그대로 쓰면
> **하한 가드가 통째로 꺼진다.** 고유값이 2개 이상 보일 때까지 창을 자동으로 넓히도록 했다.

**기본값 `1e-6` 에 대한 평가:** 매끄러운 모델에서는 실제 필요치(1e-17~1e-9)보다
크게 넉넉하고, 계단형 모델에서는 오히려 **부족하다**(필요 1.46e-3). 즉 `1e-6` 은
어느 쪽에도 맞는 값이 아니며, 실물 STRC 를 재서 정해야 한다는 §2.6 의 지적이 옳다.
