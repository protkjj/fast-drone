## 진단 (실측 근거)

첫 실패(t=46.84s) 직전 2초의 추적:
```
t=46.72s  |ω|=18.5 rad/s  T=  0.0N  ν=[+100, -19, +25]   ← 이미 텀블링 진입
t=46.78s  |ω|= 2.6        T= 60.0   ν=[-100, -34, +36]   ← 명령 bang-bang
t=46.82s  |ω|=25.6        T=  0.0   ν=[-100, +100, +100]
t=46.84s  |ω|=36.9  → QP NaN (status 4)
```
- **수치 문제가 아니라 폐루프 불안정이 먼저**: 가상명령이 20ms마다 경계(T: 0↔60N,
  ν: ±100)를 오가는 bang-bang → INDI가 충실히 실행 → 롤축(Ixx=0.02) 중심으로
  |ω| 37 rad/s 텀블링 → 그 상태의 20노드 예측이 ERK에서 폭발 → QP NaN.
- IPOPT판(같은 구조·같은 비용)은 오늘 동일 조건에서 감속 이벤트(z 4.7, max 13m,
  모터 채터링 1800)를 겪고도 **회복**함 — 5-iter 수렴 + 내장 글로벌라이제이션의 차이.
- 문헌이 경고한 "RTI는 글로벌라이제이션 부재로 대외란에서 발산 가능"이
  우리 감속 취약점(초기조건에 혼돈적 민감)과 정확히 결합된 사례.
- Δu 등가 가중이 안 먹힌 것: IPOPT의 감속 생존이 R_du 덕이 아니라 반복
  수렴 덕임을 시사 (SQP-5 실패는 별개 문제로 추가 원인 규명 필요).

## 미시도 후보 (다음 라운드 제안, 우선순위순)

1. **dt_ctrl 10ms (100Hz RTI)** — 문헌 표준은 RTI를 더 빠른 주기로 돌려 안정화
   (Romero'22: 100Hz). 솔브 0.55ms라 100Hz도 5.5% 부하. 샘플링이 빠르면 반복
   오차가 수축한다는 RTI 수렴 이론과 정합. **가장 유력.**
2. du_weight_scale 10~100× (등가 가중이 약했을 가능성)
3. hpipm_mode 'ROBUST' + qp_solver_iter_max 증가
4. IRK 적분기 (예측 폭발 지연) / AS-RTI (as_rti_iter)
5. **HybridWithFallback 결합 평가** — consec_fail 트리거가 정확히 이 상황용.
   감속 이벤트 시 LQR로 넘어가 생존하는지 (시스템 관점에선 이것도 유효한 답)
6. SQP 모드 즉시 NaN의 별도 원인 규명 (RTI가 버티는 웜스타트에서 반복이
   왜 폭발하는지 — cost_scaling/제약 상호작용 의심)

## 라운드 2 — 안정화 사다리 7단계 전부 소진 (2026-08-04 심야)

| # | 시도 | 결과 |
|---|---|---|
| 1 | 100Hz RTI (Δu 유/무) | 감속 DIV — **가상명령이 완전히 부드러운데도** 발산 (bang-bang 가설 기각) |
| 2 | 200Hz RTI | 감속 DIV |
| 3 | du_weight 30× | 감속 DIV |
| 4 | hpipm ROBUST+QP50 / IRK | 감속 DIV (IRK는 솔브 7ms로 느려지기까지) |
| 5 | AS-RTI (iter2/level3) | "생존"은 가짜 — OK 0/6500, 전 솔브 실패로 모터 동결 표류 |
| 6 | SQP 즉시 NaN 규명 | **내 버그였음**: status 2(max iter)를 실패 취급 → 매 솔브 웜스타트 파괴. 수정 후 SQP-5 정상 동작하나 감속 DIV는 여전 |
| 7 | HybridWithFallback 결합 | 트리거 작동(전환 2회)했으나 텀블(\|ω\|~37)이 LQR 선형 영역 밖 → 플랜트 NaN |

**설정 패리티 검증**: 생성된 json에서 cost_scaling=1, W/W_e가 IPOPT판과 일치 확인 — OCP 자체는 같은 문제.

### 수정된 메커니즘 이해 (플롯: results/acados_100hz_du_vc.png)
1. 감속 중 최적화기가 T를 ~15N까지 내림 (고속에선 동체 공력 양력이 무게 대체 — 물리적으로 그럴듯)
2. 모터 n→0 근처 → **INDI G(∝n) 특이화** + 개별 모터 0-클리핑 비대칭 → 롤(Ixx=0.02) 이탈
3. 텀블 진입(|ω| 37 rad/s) → GN 기반 솔버는 극한 상태에서 못 돌아옴 (IPOPT는 exact Hessian
   + 라인서치로 같은 이벤트에서 회복 — 오늘 IPOPT 단일런도 max 13m 이벤트를 겪고 살아남음)
4. T_min=20N(총추력 하한)으로는 못 막음 — 차동 할당이 개별 모터를 여전히 0으로 보냄

### 남은 미시도 방향 (kj 결정 필요)
1. **EXTERNAL cost + exact Hessian** (acados 지원) — "GN이 대잔차 구간을 못 넘는다" 가설의 직접 검증.
   RTI보다 느려지지만 ms 스케일 유지 전망
2. **n_min 아이들 도입** (예: 150 rad/s) — 실기 ESC 관행. G 특이성 근본 제거, IPOPT의 17% 사고율도
   낮출 가능성. 단 vehicle_params 변경 = 전 베이스라인 재실행 필요 (큰 결정)
3. **감속 프로파일 완화** — 미션 설계 측면. IPOPT조차 17% 사고율 = 이 15s 감속 자체가 위험 경계.
   실기라면 이 기동은 이대로 안 함

## 라운드 3 — 돌파: EXTERNAL cost + exact Hessian (kj 지시 ①②③ 실행)

| 실험 | 결과 |
|---|---|
| n_min 100/150/200 (acados 미션, 케이스별 새 솔버) | **전부 감속 DIV** — G 특이성 가설로 acados는 못 구함 (모터 바닥 150이어도 텀블) |
| **EXT+exact Hessian + SQP5 + Δu** | ✅ **감속 생존** — 감속 1.459 / 호버 0.003 / 전체 z 2.289, 솔브 10.7ms/p95 13.8ms |
| EXT+exact + RTI(1-iter) | 발산 — **exact Hessian × 복수 반복 둘 다 필요** (IPOPT 생존 요인의 정확한 재현) |
| ω 조기 트리거(12) + 복귀 허용 | 전환은 되나 복귀 후 재텀블 → DIV |
| **ω 조기 트리거(12) + 복귀 금지** | ✅ 발산 구성(GN-RTI)조차 완주 (감속 2.65, \|ω\|max 13) — LQR이 아직 유효한 영역에서 인수 |

핵심 규명 3건:
1. **GN 가설 확정**: GN 계열은 감속 대잔차를 못 넘고, exact Hessian+반복(5)이 IPOPT의 생존 요인.
   솔브 10.7ms는 50Hz 예산 안 (IPOPT 21ms의 절반, C 솔버라 실기 이식성 확보)
2. **폴백 "복귀" 경로가 위험**: acados 솔버 재개가 불안정(QP 승수 NaN 오염 — `solver.reset()`으로도
   불충분 실측) → 복귀 후 재텀블. **복귀 금지(전환 후 미션 끝까지 LQR)**가 안전 (실기 관행과 부합)
3. **ω 조기 트리거 유효** (kj 제안): \|ω\| 12에서 넘기면 LQR이 회복 가능 (37까지 가면 불가).
   단 EXT5는 스스로 회복 가능한 스파이크(~13)도 잡으므로 임계 15 근방 튜닝 여지
4. 부수: 시행 간 솔버 재사용 금지 (오염 전파) — MC류는 시행마다 새 인스턴스 필수

진행 중 (백그라운드 MC 4종): IPOPT N=10 × n_min{100,150,200} + **acados EXT5 감속진단 30회**
(`acados_decel_diag.py` — 신규 repo 스크립트). 완료 시 5m+ 발생률로 최종 판정.

## 감속진단 MC 최종 (IPOPT, 같은 코드·seed=0·30회)

| | N=20 rerun | **N=10/dt=0.1** |
|---|---|---|
| 5m+ 발생률 | 17% (5/30) | **13% (4/30)** |
| P95 | 8.62m | **7.33m** |
| 최악 | 44.30m | **14.00m** |

→ **N=10이 전 지표 승** — "수렴 안정성(전건 5-iter) > 예측 정밀도" 확정. 구 기록(20%/17.4m)은
w0 픽스 전 수치로 대체됨. 그리드 선택(IPOPT·acados 공통)에 직접 반영할 결과.
