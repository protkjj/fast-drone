  -> 개루프는 **불안정이 아니라 중립안정**이다 (실수부 <= 0, 0 인 것 2 개는 적분기).
     동체 정적안정(x_cp 가 CG 뒤) + 공력 감쇠 덕이다.
     핵심은 감쇠비가 **속도에 무관하게 0.05** 로 낮게 유지된다는 것:
       복원 강성 ~ q_bar ~ V^2  ->  wn ~ V
       공력 감쇠  ~ V           ->  zeta = const
     그래서 고유진동수만 1.93 -> 8.23 rad/s (4.3배) 커진다.
     => 제어 대역폭이 속도에 비례해 올라가야 한다. 고정 게인으로는 못 덮는다.

  [해석] 측풍이 롤이 아니라 요를 때린다.
    축대칭 무핀 동체는 압력중심이 축 위에 있어 측력이 M_z 만 만든다
    (M_static = [0, -x_cp*Fz, +x_cp*Fy]). 공력 롤 모멘트는 감쇠항 C_lp*p 뿐이고
    트림에서 p=0 이라 정확히 0 이다. Ixx 가 작아 롤이 민감한 것은 사실이나
    그건 제어·노이즈 민감도 문제이지 공력 외란 문제가 아니다.

  [해석] 요 모멘트는 **복원 방향**이다 (풍향계 안정). 부호 검사로 확인했다:
    옆미끄럼 beta 와 omega_dot_z 의 부호가 같다 = 기수가 상대풍 쪽으로 돈다.
    따라서 여유비 < 1 은 '돌풍에 무너진다'가 아니라
    **'측풍 중 지령 기수방위를 유지할 수 없다 — 풍향계로 돌아간다'** 이다.
    임무가 기수방위 유지를 요구하는지에 따라 판정이 갈린다. => 사양 확정 필요.
