# 비행 화면·조작성 복원 검증 · 2026-09-16

## 변경 이유

통합본은 관찰을 PD–INDI로 고정하고 숫자 입력 후 별도 적용을 요구해,
연구 제어기로 비행을 보면서 조작하던 흐름을 약화시켰다. 이번 변경은 이를 바로잡는다.
물리 모델, NLP 목적함수/제약, 솔버 허용오차, INDI 이득은 바꾸지 않았다.

- 비행 화면 기본 제어기는 **실제 IPOPT Hybrid**다. NMPC 단독과 PD–INDI는 직접 선택한다.
  느리다는 이유로 제어기를 자동 교체하지 않는다. PD는 조작용 baseline으로 표시한다.
- 속도·고도·풍속·바람 방향에 슬라이더와 숫자 입력을 함께 제공한다.
  슬라이더 이동 중에도 최대 약 80 ms 간격으로 요청하고, 놓으면 마지막 값을 보낸다.
  이것은 UI 요청 간격이며, 실제 적용은 다음 **시뮬레이션 20 ms 제어 경계**다.
  숫자는 입력을 마치거나 Enter로 반영한다. 빈 값·범위 밖 값은 거부한다.
- 바람은 world 방향의 실제 플랜트 입력이다. 0°=+X로 흐름, 90°=+Y,
  180°=−X이며 기상학의 ‘불어오는 방향’ 표기가 아니다. 제어기에는 참 바람을 제공하지 않는다.
- 목표·바람은 실제 적용 시각과 함께 기록되어 정밀 비교에 재사용된다.
  동일 tick에 바람을 반영하여 라이브 조작과 일정 재실행의 한 tick 불일치를 방지했다.
- 3D 위치·자세는 적분 상태를 그대로 표시한다. 기체 추적/지면/전체 궤적,
  카메라 회전·확대, 현재 좌표를 제공한다. 작은 화면에서는 비행 화면이 먼저 나온다.
  추적 시점의 1 m 격자는 초기 고도−1 m의 **시각 기준면**이며 지면이나 충돌면이 아니다.
  실제 지면 기준은 world Z=0이다. 로터 회전은 기존 시각 감속/잔상을 유지한다.
- 비교·로그는 접을 수 있는 보조 영역으로 유지한다. 예전 데모·CSV·STL·실험 원본은 보존한다.

## 자동 검사

Python 50개, 연구 Node 40개, 이전 데모 회귀 34개: **124개 통과**.
기존 수식/WASM 대조·물리·센서·할당 검사에 다음을 추가했다.

- Hybrid 및 NMPC 비행 중 조작에서도 각각의 IPOPT 실행과 INDI 유무 확인.
- PD/Hybrid/NMPC 라이브 목표·바람 기록 재실행 시 상태와 trace 일치.
- 속도 목표를 실제 속도에 직접 대입하지 않음.
- 풍향의 world 벡터 변환, 기존 gust와 기본 바람의 합성, 입력 범위 검증.
- 연속 드래그 중 자동 반영, 숫자/슬라이더 동기화, 초기 고도와 목표 고도의 구분.
- Worker 일시정지·중지·선택 제어기 실행, 로그 조건에 바람 포함.

## 실제 브라우저 검사

사용자 승인 후 별도 임시 Chrome 프로필로 로컬 배포 산출물을 검사했다.
사용자 브라우저 프로필에 붙지 않으며, 테스트가 끝나면 자기 브라우저만 정상 종료한다.

```sh
node research/browser_smoke.cjs http://127.0.0.1:8765/sim.html .08 --flight
node research/browser_smoke.cjs http://127.0.0.1:8765/sim.html .08 --extended
```

- 기본 Hybrid 선택, 네이티브 방향키로 슬라이더 변경, DOM 입력 이벤트의 자동 반영.
- Hybrid/NMPC 각각 0.08초 조작 시험: 실제 IPOPT 4회, 플랜트 80회;
  Hybrid INDI 80회, NMPC INDI 0회. 화면 위치와 최종 적분 위치 일치.
- 기본 Hybrid의 2초 전진 시험(목표 1 m/s): IPOPT 100회, 실패 0회,
  최종 X=1.625773 m, vx=0.998190 m/s, 고도=20.000219 m.
  3D 위치가 최종 적분 위치와 일치했다. 저속 명목 1회 검사이며 고속 성능 근거가 아니다.
- PD 비행에서 속도·고도·바람 변경, 측풍→역풍, 일시정지 중 위치/자세/로터 정지,
  재개 및 중지 후 부분 기록 보존. 이 PD 동작 검사를 Hybrid 성능으로 해석하지 않는다.
- 기록 재생 위치 대조, 원본 로그 불변, 바람 일정의 정밀 비교 재사용.
- 별도 정밀 비교에서 참 상태/ESKF 경로, 50 Hz/1 kHz 로그, JSON 내려받기/가져오기,
  재생·설정 재사용·풀이 경계 중지 검사. 0.08초 시험이므로 GPS 도착 검증은
  별도 자동 검사에 의존하며 이 브라우저 시험만으로 검증했다고 주장하지 않는다.
- 1280×900 / 390×844 스크린샷 확인. 수평 페이지 넘침 없음, 작은 화면은 3D 먼저.

브라우저 검사 도중 80 ms 시험이 100 ms 상태 폴링 사이에 끝나는 테스트 경합을
확인했다. 이후 프레임 수신 시 DOM 조작을 보내도록 검사 코드를 수정하여 재통과했다.
시뮬레이터를 느리게 만들거나 검증 조건을 완화해서 통과시키지 않았다.

이 검사는 조작·표시·실행 경로의 회귀 검증이다. 고속 성능·실제 기체 정확도·
장시간 안정성·Hybrid의 우위·IPOPT 20 ms 마감을 입증하지 않는다.
이전 [PD 8개 시험](UNIFIED_VALIDATION.md)과 [v2 비교](VALIDATION_V2.md)는
당시 구현의 결과로 보존하며 이번 조작성 수정의 새로운 성능 측정처럼 재사용하지 않는다.
