## 확인 조건과 방법

`trim_envelope.py`는 기존 `model.py`의 CasADi 공력·추진·모터·배터리·운동방정식을
그대로 호출하는 오프라인 진단이다. 다른 플랜트를 새로 만들지 않는다.

| 조건 | 값/범위 |
| --- | --- |
| 모델 | `profiles/selected.json`, 선정안 6931 |
| 비행 | 무풍, 일정한 +X 속도, 등고도, 무롤, 각속도 0 |
| 자세 | body +x 추력, 기수 올림 0–90° |
| 속도 표본 | 0, 5, 10, 15, 20, 30, 40, 60, 80, 83.3, 90, 100 m/s |
| 배터리 | SOC 1.0 / 0.5 / 0.2: 총 36개 명목 작동점 |
| 민감도 | 압력중심 ±0.01 m 또는 CN 두 계수 ×0.8/×1.2, 각각 15/40/83.3 m/s |
| 수치 수용 | 병진 가속도 <1e-7 m/s², 각가속도 <1e-6 rad/s², 로터 가속도 <1e-5 rad/s² |
| 추가 조건 | 로터 추력 ≥0, 회전수·전류·전압·프롭 맵·나선 팁 마하 조건 |

SOC를 고정해 순간 작동점을 평가하되, 실제 RHS의 SOC 감소는 그대로 확인한다.
배터리까지 영원히 평형이라는 뜻이 아니다. 통과도 안정성·외란 대응 여유·실물
안전성의 증명이 아니다. 아래 경계는 0.5 m/s 탐색 격자의 부호 변화를 찾아
세밀하게 푼 결과이며, 다른 자세·선회·상승·가속 경로의 전체 최적화 결과가 아니다.

### 힘만 맞춘 해와 자세까지 유지하는 해의 차이

기수 올림각을 θ, 무게를 W, 공력의 body x/z 성분을 Fx/Fz라고 하면:

```text
body 속도 = [V cosθ, 0, −V sinθ]
수직/수평 가속도 0  →  Fz = W cosθ,  T = W sinθ − Fx

공력 피치 모멘트 My = −cp_offset × Fz
피치 방향 로터 팔 길이 a = arm / √2

T1 = T2 = (T − My/a) / 4       # body z=+a 쪽 두 로터
T3 = T4 = (T + My/a) / 4       # body z=−a 쪽 두 로터
```

현재 압력중심은 CG보다 body x 방향으로 −0.088706 m, `a=0.119385 m`다.
법선력이 기체를 돌리므로 두 로터 쌍의 추력을 다르게 만들어 반대 모멘트를 내야 한다.
쌍 내 회전수는 같아서 롤 반작용 토크와 요 모멘트가 상쇄된다. 구한 결과를
원래 18상태 RHS에 다시 넣어 병진·회전·모터의 잔차를 각각 검사한다.

필요 추력에 음수가 나오면 0으로 잘라 성공 처리하지 않는다. 비음수 추력으로
만들 수 있는 피치 모멘트에는 `|My| ≤ aT`라는 상한이 있기 때문이다. 반대로
모든 추력이 양수라고 전류·전압까지 통과한 것은 아니다.

## 명목 결과

무롤·무풍 등속 수평비행, SOC 100%. 각 쌍의 숫자는 **로터 1개당 추력**이다.

| 속도 | 힘 평형의 α | 총추력 | T1=T2 | T3=T4 | 최종 판정 |
| --- | ---: | ---: | ---: | ---: | --- |
| 호버 | 정의 안 됨(자세 90°) | 16.786 N | 4.197 N | 4.197 N | 모델 조건 통과 |
| 10 m/s | 74.238° | 16.384 N | 3.249 N | 4.943 N | 모델 조건 통과, 고받음각 미검증 |
| 15 m/s | 51.061° | 13.542 N | 1.426 N | 5.345 N | 모델 조건 통과, 고받음각 미검증 |
| 20 m/s | 33.403° | 10.071 N | −0.085 N | 5.121 N | 음의 추력 필요 |
| 40 m/s | 10.098° | 5.983 N | −1.574 N | 4.566 N | 음의 추력 필요 |
| 60 m/s | 4.727° | 7.936 N | −1.124 N | 5.091 N | 음의 추력 필요 |
| 83.3 m/s | 2.509° | 13.029 N | 0.142 N | 6.373 N | 전류 상한 초과 |

40 m/s에서는 필요한 피치 모멘트가 1.466 N·m인데, 이 총추력과 무롤 배치로
만들 수 있는 최대값은 0.714 N·m다. 단순히 모터 최대 RPM을 높여도 **주어진
등속 평형의 총추력**에서는 해결되지 않는다. 총추력을 올리면 가속도도 바뀐다.
참고로 전체 반경 `arm × T`를 써도 약 1.010 N·m여서, 이 작동점은 이상적인
팔 방향 재배치만으로도 충분하지 않다. 전체 비행경로 불가능의 증명은 아니다.

83.3 m/s의 요구 회전수는 두 쌍 각각 약 **24,150 / 29,473 rpm**, 전류는
각각 **6.688 / 45.609 A**다. 높은 쌍의 초기 회전수 미분은 약 −2,727 rad/s²:
바로 그 순간 기체 힘·모멘트가 맞아도 로터가 느려지며 균형이 깨진다.
전류 상한은 다음 코드 정책에서 나온 값이며, 실측 정격으로 확인된 값이 아니다.

```text
min(가정한 모터 상한 40 A,
    배터리 4.2051476 Ah × 40 C × ESC 효율 0.95 / 로터 4개)
= 39.9489025 A
```

이 배터리 항은 로터별로 균등하게 배정한 보수적 상한이다. 배터리 DC 전류와
모터 전류를 동일하게 취급하거나 이를 실물 ESC 사양으로 해석하지 않는다.
SOC 100/50/20% 모두 전류 제한 실패가 남았다. 실패 작동점의 진단 전력에는
로터 감속 에너지 효과가 섞이므로 이를 정상 순항 소비전력으로 보고하지 않는다.

### 실제 적분 교차 검사

제어기를 붙이지 않고 구한 회전수 명령을 유지하며, 기존 1 kHz RK4로 100 ms 적분했다.

- 15 m/s: 자세·속도·회전수 유지, SOC만 약 0.000129 감소.
- 83.3 m/s: 높은 쌍의 회전수 약 76.34 rad/s 감소, 피치 각속도 약 0.1253 rad/s
  발생, 속도 변화 `[−0.07465, 0, −0.08566]` m/s. 평형이 유지되지 않았다.

따라서 실패는 단순 최적화 반복 횟수 부족으로 판정한 것이 아니다. 원래
사이징의 같은 RPM 4개를 기체 RHS에 넣으면 피치 각가속도도 약 42.54 rad/s²다.

## 원본 사이징·고받음각 공력의 의미

고정 리비전 `db793a7039c76c9937597a240efc94f68c5a8af0`의
[prop.py](https://github.com/gocksk/Rocket-Drone-Project/blob/db793a7039c76c9937597a240efc94f68c5a8af0/modules/prop.py)는
순항의 총추력/자세각을 **힘 평형 두 식**으로 정한다. 6DOF 자세 모멘트와
로터별 차등 추력을 풀지는 않는다. 이번 힘 평형은 원본의 약 2.509°/13.029 N을
0.1% 이내로 재현한다. 그러나 원본의 ‘작동점 가능’과 이번 ‘전체 평형 가능’은
검사 범위가 다르다. 기존 `test_selected_cruise_propeller_anchor`도 처음부터
프롭 작동점만 비교하며 전체 6DOF 평형 일치를 주장하지 않는다.

[aero.py](https://github.com/gocksk/Rocket-Drone-Project/blob/db793a7039c76c9937597a240efc94f68c5a8af0/modules/aero.py)는
Barrowman 계열 법선력과 `sinα cosα`/`sin²α` 크로스플로 확장을 사용한다.
원본 자체가 형상·크로스플로 계수의 실측 보정 전 정확도를 보장하지 않는다.
[constants.py](https://github.com/gocksk/Rocket-Drone-Project/blob/db793a7039c76c9937597a240efc94f68c5a8af0/constants.py)의
항력 보정 `k_cal=1.0`도 확인했다. 현 연구 모델은 고정 CP에 모든 법선력을 적용한다.
고받음각에서 CP 이동, 박리, 프롭 횡유입, 동체/프롭 간섭이 검증된 모델은 아니다.

따라서 ‘수식이 모든 각도에서 계산된다’와 ‘그 각도에서 실제 기체를 정확하게
예측한다’는 구분해야 한다. 공력이 에너지를 만들어내지 않는 수동성 검사도
유효 범위의 실측 검증을 대체하지 않는다.

현재 런타임의 RPM 제한은 회전 성분만 포함한다. 이번 도구에는 원본 사이징의
`sqrt(V²+(nD/2)²)/음속` 나선 팁 마하를 **진단**으로 추가했다. 83.3 m/s는 약
0.658로 기준 0.7 이내지만, 90 m/s는 약 0.703으로 초과한다. 이 식 역시
고받음각의 블레이드 방위각별 상대속도/유도류를 푸는 모델이 아니며, 비행 중
제약으로 새로 적용하거나 물리식을 변경하지 않았다.

프로필은 바꾸지 않고 메모리 복사본에서 계산했다. 15 m/s는 네 경우 모두 모델
조건을 통과했고, 40 / 83.3 m/s는 다음 문제가 남았다.

## 다음 결정 순서

1. **모델/설계 근거 확인:** CG·CP·로터 위치와 축 부호는 계산상 대조했다.
   다음은 실제 배치, 받음각별 힘/모멘트, 모터·ESC 전류 및 프롭 성능의 근거다.
   40 A 가정을 올리거나 CP를 옮겨 결과를 맞추는 변경은 하지 않는다.
2. **평형 가능한 시험 조건 확정:** 양의 추력뿐 아니라 모터 여유와 모멘트 여유를
   검사한다. 필요하면 실제 설계에 근거해 CG 배치·자세 제어 장치·추진 구성을
   수정해야 한다. 데이터 전에는 분명히 표시한 별도 가정 모델로만 비교한다.
3. **전이 경로 검사:** 저속부터 매 순간 등속 수평 평형을 잇는 방식은 현재 모델에서
   성립하지 않는다. 가속/상승을 허용하는 경로는 별도로 운동방정식과 모터 지연을
   포함해 검사해야 한다. 이것만으로 목표점의 정상 유지 불가를 해결할 수는 없다.
4. **제어기 공정 비교:** 그 다음 동일한 플랜트·센서·외란·물리 제약에서 Hybrid와
   NMPC를 비교한다. 비교 시 처음부터 불가능한 목표와 정상 목표를 구별한다.

실측 받음각 범위가 없으므로 이번 점검에서 새 α 제한값이나 전이 경로를
확정하지 않았다. 선정 모델의 목표 달성 가능성을 먼저 확인하는 진단 단계다.
