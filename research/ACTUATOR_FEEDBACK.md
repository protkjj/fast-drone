# Hybrid의 모터 능력 피드백

## 범위

선정 기체 연구 엔진(`research/`)의 NMPC–INDI 인터페이스만 보강한다.
복원한 메인 `/sim.html`의 화면·물리·제어기는 변경하지 않는다. 연구 엔진의
기존 플랜트, 추진 맵, 비용 가중치, 50 Hz / 1 kHz 주기와 NMPC 단독도 유지한다.
상위 NMPC는 여전히 13상태와 `[T, alpha_x, alpha_y, alpha_z]`를 최적화한다.
실제 네 모터 명령을 만드는 주체는 INDI다.

## 양방향으로 주고받는 것

기존의 `requested → allocated` 결과 피드백에 다음 정보를 추가했다.

1. **INDI 쪽에서 계산:** 관측 회전수, 속도·자세, 최근 버스 전압으로 모터 응답을
   20 ms 예측한다. 공통 `model.py`의 전류·전압 제한, 로터 관성, 마찰과 수동 감속
   방정식을 1 ms RK4로 적분한다. 별도 추력 변화율 상수를 임의로 맞추지 않는다.
2. **모터별 범위:** 회전수 명령 0 / 최대를 각각 유지한 결과에서 다음 20 ms 끝의
   로터 힘 하한·상한을 구한다. 감속에도 시간이 걸리므로 현재 추력이 바로 0이
   된다고 가정하지 않는다. 역기전력보다 전압이 낮아 수동 감속만 가능하면,
   가능한 힘이 한 값인 등식 제약도 보존한다.
3. **결합된 가상입력 범위:** 같은 기하·추진 맵으로 `nu = A f + b`를 구성한다.
   총추력/피치/요의 힘 관계는 선형이고, 롤 반토크는 힘–토크 구간의 할선으로
   근사한다. `b`는 동기 필터의 각가속도·로터 힘/토크로 추정한 잔여 항이다.
4. **NMPC에 적용:** 첫 가상 명령에만
   `f_lower <= A_inverse (nu_0 - b) <= f_upper`를 추가한다. 네 축을 독립적으로
   잘라서 동시에 불가능한 추력·자세 조합을 허용하지 않는다. 추가 결정변수나
   모터 상태는 없고, 네 개의 힘 단위 제약만 늘어난다.

이 범위는 50 Hz마다 관측값으로 새로 계산한다. 미래 1초에 오늘의 범위를 그대로
적용하지 않는다. NMPC의 나머지 예측 입력과 50 ms 예측 격자는 기존과 동일하다.
첫 명령은 실제로 20 ms 후 재계산된다. 변경되는 국소 제약의 쌍대 웜스타트는
0으로 초기화하고, 기체 상태·가상입력 궤적의 기존 웜스타트는 유지한다.

## 보장하지 않는 것

- **명목 국소 범위이지, 엄밀하게 인증된 도달 가능 집합이 아니다.** 20 ms 동안
  유입속도와 최근 측정 전압을 고정한다. 향후 배터리 전압 강하, 바람, 모델 오차를
  정확하게 예견하지 않는다. SOC와 실제 플랜트 오차 계수를 몰래 읽지 않는다.
- 롤의 비선형 힘–토크 관계는 할선 근사다. 구간 중간점의 오차를 로그에 남기지만,
  이는 구간 전체의 오차 상한 증명이 아니다. 로터 가속 반작용도 할당에 직접
  포함하지 않는다. 맵 밖 공력/추진 조건에는 기존 경고가 그대로 적용된다.
- **20 ms 후 낼 수 있는 힘과 지금 내는 힘은 다르다.** 상위 13상태 동역학은
  여전히 가상입력이 즉시 작용한다고 예측한다. INDI의 명목 힘 역산 명령이 예측한
  끝점까지 정확히 데려간다는 보장도 없다. 전체 지연 보상을 완료한 것이 아니다.
- 제약이 특이하거나 유효한 국소 힘 좌표를 만들 수 없으면 `available:false`와
  이유를 남긴다. 그 계산에서는 기존 상위 입력 범위를 사용하고 물리 포화·INDI는
  유지한다. 이 횟수를 결과에서 숨기지 않는다.
- IPOPT 실패 시 기존의 직전 명령 유지 정책은 바꾸지 않는다. 유지한 명령이 새
  범위를 위반할 수도 있으므로 `envelope_violation_N`을 실패 때도 기록한다.
  임의 투영으로 명령을 바꾸고 최적화가 성공한 것처럼 처리하지 않는다.
- 모터 관성·속도 루프·전류 한계 등 선정 프로필의 기존 가정은 가정 그대로다.
  이 보강은 실제 모터 식별이나 하드웨어 비행 검증을 대체하지 않는다.

## 기록과 전후 비교

`hybrid_actuator_feedback`은 켬/끔 절제 실험용 설정이다. **기본값은 false**다.
초기 비교에서 모터 추종 잔차는 줄었지만 고도 오차 증가와 풀이 실패가 남았으므로
기존 동작을 자동 교체하지 않는다. 로컬 연구 페이지에 `?actuator_feedback=1`을
붙이면 실험 옵션을 켤 수 있다. 기존 모드 쿼리가 있으면 `&actuator_feedback=1`을
붙인다. 안내 문구에 실험 옵션 ON을 표시하며, 화면 배치/조작기는 바꾸지 않는다.
플랜트, 비용, 목표,
센서, 난수 seed와 NMPC 단독은 바꾸지 않는다. 껐을 때 추가 제약은 비활성이다.
오래된 로그에서 이 설정이 없으면 `false`로 해석하며, 재사용 시에도 유지한다.

- `solves[].actuator_envelope`: 사용 시각, 전압·유입속도, 초기/상하한 회전수,
  힘 경계, 가상입력 변환, 이용 가능 여부와 롤 할선 중간점 오차.
- `solves[].envelope_force_N`, `envelope_violation_N`: 실제로 반환한 첫 명령의
  국소 힘 좌표와 제약 위반. 단위 N으로 확인한다.
- `metrics.actuator_envelope_unavailable`: 요청했지만 범위를 만들지 못한 횟수.
- `virtual_thrust_tracking_rmse_N`, `virtual_alpha_tracking_rmse_rad_s2`: 요청과
  실제 플랜트 반응의 차이. 실제 각가속도는 **평가에만** 사용하며 제어기에 전달하지 않는다.
  기존 정적 배분 잔차와 물리 지연에 따른 추종 잔차를 구분한다.

재현 명령(출력은 새 파일명을 사용):

```sh
python3 -m research.build_bundle
python3 -m pytest research/test_model.py research/test_estimator.py research/test_nmpc.py control/test_research_parity.py -q
npm test --prefix research
node research/validate_actuator_feedback.cjs research/generated/actuator-feedback-new.json
```

비교는 속도 변경(참 상태/ESKF), 고도 급강하, 측풍 ESKF의 네 조건 × 켬/끔이다.
전 사례와 실패를 보존하며, 짧은 단일-seed 결과로 Hybrid의 일반적 우월성이나
정착 시간, 실시간 20 ms 마감을 주장하지 않는다.
