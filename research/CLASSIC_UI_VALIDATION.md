# 기존 시뮬레이터 배치·단축키 복원 · 2026-09-16

이 문서는 `177212f`의 연구 UI 수정 기록이다. 이후 사용자는 재구성한 화면이 아닌
원래 앱으로 복원을 요청했다. 현재 공개 메인과 보존 범위는
[원래 시뮬레이터 복원](../gz_aero/SIMULATOR_RESTORE.md)을 참고한다.

사용자가 대시보드식 통합 화면보다 종전 시뮬레이터의 조작성을 원했다.
`gz_aero/tools/build_sim.py`의 색상·3열 배치·키보드 조작을 기준으로 화면을 복원했다.
종전 8 kg 데모의 물리 코드를 다시 연결한 것은 아니다.

## 변경 범위

- 왼쪽: 시작/일시정지 한 버튼, 초기화, 제어기와 네 목표·바람 슬라이더, 계기.
- 가운데: 큰 STL 비행 화면, 카메라 버튼, 하단 시간축과 실시간 그래프 3개.
- 오른쪽: 선정 기체 시험 설정, 정밀 비교·기록, 모델의 가정과 한계.
- `Space`: 시작 / 일시정지 / 재개. 종료한 기록을 보고 있으면 재생 / 정지.
  슬라이더에 초점이 남아 있어도 동작한다. 숫자·텍스트·메뉴 입력은 가로채지 않고,
  버튼의 네이티브 Space 동작도 중복 실행하지 않는다. 키 반복·조합키는 무시한다.
- `R`: 현재 풀이 경계에서 안전하게 종료한 뒤 초기 화면으로 돌아간다.
  직전 결과는 저장·재생할 수 있게 보존한다. 다음 **새 비행**을 시작하면 실행 결과를 교체한다.
- `F`: 기체 위치 따라가기. 뒤/옆/위/기수축 시점, 회전·휠 확대·Shift+드래그 이동.
  이 조작들은 카메라만 변경한다. 양쪽 패널 경계는 드래그·방향키로 조절한다.
- 그래프는 비행 중 전달된 프레임으로 갱신하고, 종료 후 전체 기록으로 그린다.
  총 받음각은 body +X와 공기 상대속도 사이의 각도이며 상대속도 0.5 m/s 미만은
  방향 미정으로 표시한다. 목표/실제 속도, 고도를 잘라 맞추거나 재적분하지 않는다.
  글자는 고정된 큰 SVG를 축소하지 않고 실제 표시 픽셀 크기로 그린다.
- 타임라인은 **종료한 기록의 탐색·재생**이다. 비행 중 되감아 제어기·추정기 상태까지
  복원하는 기능은 아니다. 이전 데모의 모든 기능을 그대로 이식했다고 주장하지 않는다.

`model.py`, `nmpc.py`, `eskf.py`, `runtime.js`, `worker.js`, 기체 프로필·STL은 변경하지 않았다.
기본은 실제 IPOPT Hybrid다. NMPC 단독 / PD–INDI 선택 및 정밀 비교도 유지했다.
입력 해시는 `3dbac3df91b9f7e1f0a0b822ed9ed20ef466a51fd183c6d618e5e093ae603b0f`로 동일하다.
CSS도 페이지/스크립트와 함께 해시 버전을 붙여 배포한다.

## 검증

- Python 50개 + 연구 Node 43개 + 이전 데모 회귀 34개 = **127개 통과**.
- 추가 단위 검사: Space의 초점/반복/요청 승인 상태, R의 종료 후 기록 보존,
  F 연결, 공기 상대 각도와 그래프 표시 크기.
- 실제 Chrome 별도 임시 프로필에서 `browser_smoke.cjs --classic`:
  기본 Hybrid를 Space로 시작하여 IPOPT 4회 성공;
  이후 명시적으로 PD를 골라 방향키·포인터 슬라이더 조작, 슬라이더 초점에서 Space 정지,
  위치·자세·로터 정지, 숫자 입력 예외, 버튼 Space의 단일 실행, 재개,
  F·카메라 4개 시점·Shift 이동·패널 폭·R·기록 시간축·재생을 검사한다.
  이 PD 조작 검사를 Hybrid의 성능 측정으로 해석하지 않는다.
- 1280×900 / 390×844 캡처를 직접 확인. 가로 넘침 없음, 데스크톱 그래프는
  화면 안에 있고, 작은 화면에서는 3D가 조작부보다 먼저 나온다.
- `--flight`와 `--extended`로 기존 Hybrid/NMPC 비행, 목표·바람 변경,
  정밀 비교/ESKF, JSON 저장·가져오기와 재생 경로도 회귀 검사한다.

```sh
python3 gz_aero/tools/build_site.py --research
node research/browser_smoke.cjs http://127.0.0.1:8765/sim.html .08 --classic
node research/browser_smoke.cjs http://127.0.0.1:8765/sim.html .08 --flight
node research/browser_smoke.cjs http://127.0.0.1:8765/sim.html .08 --extended
```

이번 변경은 UI 회귀 수정이다. 고속 비행·실제 기체 정확도·Hybrid 우위·IPOPT 20 ms
마감 성능을 새로 입증한 것은 아니다. 이전 검증 결과는 해당 버전의 기록으로 보존한다.
