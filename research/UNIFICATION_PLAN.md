# 선정 기체 화면 통합

목표: 하나의 선정 기체 플랜트에서 관찰과 정밀 비교를 수행한다. UI 통합을
실측 정확도 향상이나 Hybrid 우위 검증으로 오해하지 않도록 한다.

구현·검증 기록: [UNIFIED_VALIDATION.md](UNIFIED_VALIDATION.md).

1. 공통 실행 경로에 관찰용 PD–INDI와 벽시계 페이싱을 추가한다.
   플랜트/모터/배터리/센서의 1 ms 적분과 잡음 순서는 두 모드에서 동일하다.
2. 관찰 중 목표 변경은 시뮬레이션 tick에 기록한다. 기록한 목표 일정은
   같은 조건의 정밀 비교에 재사용한다. 목표를 실제 속도에 직접 대입하지 않는다.
3. 공통 화면에서 관찰/비교를 전환한다. 선정 기체가 기본이며, 단순 검증 모델과
   이전 8 kg 데모는 별도 명시한다. 기존 공개 sim.html 진입점을 통합 화면으로 바꾼다.
4. 같은 명령을 적용했을 때 페이싱 유무가 상태·센서·에너지 지표를 바꾸지 않는지,
   명령 재현·중지·기존 제어기 회귀·사이트 진입점을 검증한다.
5. 검증 범위와 계산 속도를 기록한 후 bulnabi에 배포한다.

관찰용 PD–INDI는 NMPC–INDI Hybrid가 아니다. 실측 추진/센서 파라미터,
고속 신뢰도, INDI 동적 보상, 실제 IPOPT 20 ms 마감은 별도 연구 과제다.
