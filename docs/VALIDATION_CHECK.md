## 실제 실행으로 확인한 범위

기체·제어기 튜닝은 하지 않았다. 아래는 검증 체계 구현 확인이며 최종 강건성 입증이 아니다.

| 실행 | 조건 | 관찰 |
|---|---|---|
| 기본 성능 | 70 m/s, 50 m, 55초, GS-LQR / Split | GS-LQR은 완주, Split은 감속 중 36.4초에서 최적화 5회 연속 실패로 중단 |
| 독립 돌풍 | 70 m/s, 3초 정상 + 1초 돌풍 + 6초 회복 | 무돌풍 대조군, 수직/측방 2 m/s 각각 두 제어기가 추종·회복·모델 범위 기준 통과 |
| 스윕 실행 확인 | 질량 ×0.9/1.0/1.1, GS-LQR, 각 55초 | 3조건 완주 및 추종 기준 통과, 모두 추진 모델 범위 밖 구간 존재 |
| MC 실행 확인 | 9인자 독립 ×0.8–1.2, seed=42, GS-LQR, 3회 ×55초 | 3회 완주, 추종 기준 통과는 1회, 모두 추진 모델 범위 밖 구간 존재 |
| 조건 생성 확인 | MC 100회, 두 비교군 | dry-run으로 조건 100개/실행 200회 생성 확인; 100회 전체 물리 시뮬은 수행하지 않음 |

기본 GS-LQR의 추진 모델 범위 밖 체류 비율은 약 22.87%다. 따라서 완주·추종 기준을
충족해도 최종 `passed`는 false다. Split의 중단 전 RMSE를 GS-LQR의 55초 전체
RMSE와 그대로 비교하지 않는다. 돌풍 종료 때 이미 회복 허용 오차 안에 들어온
경우 회복 시간은 0초로 기록된다. 이는 외란 영향이 0이었다는 뜻이 아니다.
